01 | MACHINE LEARNING

FraudMail

A phishing detection web application that analyzes email screenshots using optical character recognition (OCR) and machine learning. Built with Django, it extracts text from uploaded screenshots using Tesseract OCR and feeds the extracted text into a trained scikit-learn Logistic Regression classifier that predicts whether an email is potentially fraudulent.

Python Django Scikit-learn Tesseract OCR

02 | GAME DEVELOPMENT

RockBlaster

RockBlaster is a fast-paced, retro-inspired arcade shooter built in Lua using PICO-8. It features randomized asteroid encounters, increasingly difficult levels, collision detection, and multiple weapons, including rapid-fire projectiles and a charge-based plasma beam. Custom sprites, sound effects, player health management, and interactive game-state transitions bring the action together.

Click the game to start. Use arrow keys to move, Z to shoot, and X to activate the SUPER beam or continue after a level ends.

Lua PICO-8 Collision Detection State Machine
